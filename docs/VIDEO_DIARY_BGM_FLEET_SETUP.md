# 视频日记固定 BGM：多电脑设置

## 固定曲目

- 剪映名称：`科技主题  Global Technology Background`
- 剪映素材 ID：`7377866594003568681`
- 搜索词：`科技感 轻快 纯音乐`
- 曲目时长：约 2 分 45 秒
- 类型：剪映 VIP / PGC 音乐

## 每台运行电脑只做一次

1. 安装并打开剪映专业版。
2. 登录具备该曲目权益的同一账号。
3. 打开视频日记固定模板。
4. 在音乐搜索中输入完整名称；若完整名称搜不到，输入
   `科技感 轻快 纯音乐`，并核对素材 ID。
5. 下载并加入 BGM 轨道。
6. 人声轨执行“人声分离 → 仅保留人声 → 音量 +10.0dB”；BGM 初始音量使用 -8.0dB，淡入和淡出各 1 秒。
7. 保存为本机固定视频日记模板。
8. 导出前确认曲目仍可用，并完整听审人声遮挡、节奏和结尾。

以后每条普通视频日记直接复制该模板并替换视频、日期、Day、标题和字幕，
不再重新搜索或选择音乐。

之前的参考草稿使用约 -24dB，实际听感偏弱。本版把模板起始值调整为
-8.0dB；这只是统一剪映参数，不代表人工听审通过。导出后必须检查响度与真峰值；
若出现削波、机器人音或 BGM 压住人声，保持人工听审为 `NOT_REVIEWED` 或 `FAIL`，
不得仅因参数已正确设置就标记发布通过，也不得在没有新指令时擅自偏离
“人声 +10.0dB、BGM -8.0dB”的固定规格。

## 为什么更新包不包含音乐文件

剪映草稿显示该曲目为 VIP、已购买的 PGC 音乐，但剪映素材许可不允许把单独
音乐缓存下载、复制或分发给其他电脑，也不允许把缓存文件拿到剪映外单独使用。
因此：

- 更新包只记录曲名和素材 ID；
- 不包含剪映缓存文件；
- 每台电脑必须在剪映内由有权益的账号下载；
- 若需要完全自动的 Python/FFmpeg BGM，必须换成另行取得可复制、可商用、
  可跨设备分发授权的音乐文件。

## 更新方式

已经安装并成功运行工作流的电脑不需要重装。使用视频日记增量更新包覆盖指定
代码和预设，脚本会先备份旧文件，再运行 `doctor --strict` 和全部测试；失败时
恢复备份。
