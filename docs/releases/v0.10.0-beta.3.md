# v0.10.0-beta.3 downloadable macOS Skill pre-release

Release date: 2026-08-14

## Purpose

This patch replaces the end-user copy-and-paste installation prompt with a downloadable macOS
package. The user downloads one ZIP, unzips it, double-clicks `安装.command`, reopens Codex,
and can then describe the video task normally.

## Required acceptance

- release ZIP contains exactly one `ai-video-editing-skills/` top-level directory;
- required root Skill files and the executable installer are present;
- SHA-256 sidecar matches the published ZIP;
- installer succeeds in an empty isolated `CODEX_HOME`;
- an existing installation is preserved as a timestamped backup;
- installed root Skill validation and strict doctor pass on the release machine;
- published release asset is anonymously downloadable and installable;
- full automated suite, synthetic render, complete decode and release validation pass.

## Unchanged gates

This is still a Beta release. Factory unattended production remains disabled. Case-study model,
fact, privacy, translation and first-render acceptance remain gated. Jianying login, membership,
licensed BGM, customer media and human listening/viewing approval remain external.
