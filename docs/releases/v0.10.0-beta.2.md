# v0.10.0-beta.2 one-click Skill pre-release

Release date: 2026-08-14

## Purpose

This patch fixes the public distribution contract. The repository root is one installable Codex
Skill named `ai-video-editing-skills`; the three scene directories are internal routed workflows,
not standalone installation units.

## Required acceptance

- install public tag path `.` with the official Skill installer and an explicit name;
- validate the installed root `SKILL.md` and `agents/openai.yaml`;
- run the strict doctor from outside the repository;
- confirm shared `core`, presets, scripts, schemas, and all scene manifests are present;
- run the full automated suite with no failures;
- verify anonymous GitHub homepage, API, archive, and clone access.

## Unchanged gates

Factory unattended production remains disabled. Case-study models and first-render acceptance are
not bundled. Jianying login, membership, licensed BGM, customer media, and human listening/viewing
approval remain external.
