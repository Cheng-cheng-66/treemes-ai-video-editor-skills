# v0.10.0-beta.5 complete factory workflow hotfix

Release date: 2026-08-14

## Why

Beta.4 could produce a technical open-tool preview and leave Jianying as a later supervised step.
On a recipient Mac, missing FFmpeg and skipped Jianying processing led to that rough preview being
delivered without native denoise or subtitles. That behavior violates the complete-workflow
contract.

## Fix

- the installer verifies or installs FFmpeg/ffprobe and Node through an existing Homebrew setup;
- installation stops before activation when dependencies or Jianying 7.9.0 are unavailable;
- complete factory execution is now the default and launches Jianying after four-track staging;
- Codex Desktop must use computer control and retain timeline, subtitle, denoise, mix, and export
  evidence;
- `finalize` refuses completion until the real export decodes and every sentence/whole-video human
  review field passes;
- technical preview requires an explicit command and is named
  `technical_preview_NOT_DELIVERABLE.mp4`.

## Boundary

This does not pretend a Python process can independently make semantic listening judgments or
bypass Jianying login, membership, permissions, or licensing. Those are mandatory interactive
gates. The fix ensures their absence blocks delivery instead of silently degrading quality.
