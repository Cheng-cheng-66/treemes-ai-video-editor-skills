# v0.10.0-beta.4 executable factory-shoot pre-release

Release date: 2026-08-14

## Purpose

This patch removes the incorrect public-package block on factory shooting. Factory shoot and
product promotion now route to an executable supervised-hybrid Beta workflow rather than stopping
at `BLOCKED_DISABLED_SKILL`.

## Executable output

- normalized visual analysis, transcript, sync zones, edit plan and continuity report;
- protected A/B/C/D sync-zone contract and complete action anchors;
- `picture_master_no_audio.mp4`, `dialogue_raw.wav`, `ambience.wav`, `bgm.wav`;
- locked title, verbatim single-line subtitles and actual font-width validation;
- stereo `fallback_preview.mp4` and full technical quality report;
- Jianying V1/A1/A2/A3 import manifest and sentence-by-sentence human review form.

## Required acceptance

- factory manifest is enabled and its entrypoint loads;
- synthetic A → C with two dialogue ranges → A workflow renders and fully decodes;
- C-zone picture uses one continuous source range while dialogue pauses are independently cut;
- source aspect is inherited and action anchors cannot cross picture cuts;
- package validation, all automated tests, both synthetic smoke tests and root Skill validation
  pass;
- macOS ZIP installs into an isolated `CODEX_HOME` and runs the factory synthetic workflow from
  the installed copy;
- published release assets are anonymously downloadable and checksum-valid.

## Honest boundary

The open preview is a real rendered candidate, not a Jianying-native master. Jianying noise
reduction, exact sentence listening, professional terms, actual lip sync, action completeness,
story completeness, BGM balance and perceptual continuity stay `null` until a human performs the
review. This remains a Beta pre-release, not stable or unattended final acceptance.
