# Complex 样片

## 当前候选

没有找到可用于正式发布验收的复杂真实原素材。当前状态：`MISSING`。

既有 V5 成片和合成技术样片不能冒充复杂真实原素材；工厂实拍素材属于不同场景 Skill，也不能替代视频日记验收。

## 一条候选素材必须同时或组合覆盖

- 多处长短气口
- 较长字幕，接近安全区宽度边界
- `MES系统`、`标准工时`、`标工计件`、`设备节拍` 等专业词
- 可变日期和 `Day<number>`
- 快速说话、跳切或动作锁定等音画同步风险
- 明暗变化
- 人物或镜头明显移动

## 登记门槛

- 必须是真实视频日记原素材。
- 必须有合法使用权限。
- 必须记录绝对路径、大小、SHA-256、ffprobe 和只读状态。
- 必须给出为什么覆盖上述风险的时间码说明。
- 不能使用合成视频得出发布 PASS。

缺失项详见 `missing_checklist.md`。
