# Abnormal 样片与故障场景

当前没有一套已登记、可复核的异常真实素材。所有场景默认 `MISSING` 或 `NOT_RUN`；现有合成技术样片不得冒充异常真实发布验收通过。

| 场景 | 所需输入/方法 | 当前状态 |
|---|---|---|
| 输入不存在 | 指向不存在的真实素材路径，验证清晰错误 | DEFINITION_READY |
| 无音轨 | 一份合法、真实、无音轨的视频素材 | MISSING |
| 素材损坏 | 一份可安全复制后截断的测试副本，保留原件 | MISSING |
| 字体缺失 | 独立本机配置指向不存在字体 | DEFINITION_READY |
| 输出无权限 | 临时只读目录，不使用系统或用户重要目录 | DEFINITION_READY |
| 日期元数据缺失 | 合法且缺少拍摄日期元数据的真实素材 | MISSING |
| 渲染中断 | 在测试副本任务上发送中断并检查残留/日志 | NOT_RUN |
| 重复执行 | 同一输入、配置和版本连续运行两次并对比 | NOT_RUN |

## 安全要求

- 故障注入只能作用于临时副本和专用临时目录。
- 不得截断、改名、chmod 或覆盖任何原素材、历史成片或用户目录。
- “重复执行一致性”必须比较输出规格、时长、字幕事件、模板哈希及允许的编码差异；未经规则定义不得直接宣称文件字节一致。
