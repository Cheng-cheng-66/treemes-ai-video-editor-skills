# 视频日记默认剪辑预设

本目录是以后所有“视频日记”视频的固定默认规范。渲染前读取六个 YAML 文件，并执行以下顺序：

1. 在分析、套模板或渲染前先用 `ffprobe` 读取源视频宽高、像素宽高比和旋转元数据，确定实际显示方向。
2. 用户没有指定输出画幅时必须继承源方向：横屏源输出 1920×1080（16:9），竖屏源输出 1080×1920（9:16），禁止默认套用竖屏。
3. 只有用户明确要求转换画幅时，才允许在 `edit_plan.json` 写入目标比例、`aspect_ratio_override_authorized: true` 和转换原因；缺少任一项即阻止渲染。
4. 读取明确发布信息确定日期和日记序号；只有 `date.text` 与 `day.text` 可以变化。
5. 完全复用与所选横/竖画幅对应的 `cover.yaml` 封面状态，只覆盖成片第 1、2 帧；封面包含内容标题但不显示口播字幕。
6. 第 3 帧开始进入正文，并按 `header.yaml` 显示顶部常驻模板直至视频结束；不为封面插入静音或延长成片。
7. 先删除已批准的无效内容，再按 `edit_plan.json` 的判断使用 1.00～1.08 倍速；没有明确判断时固定 1.00。
8. 画面按每条素材的实际情况分类处理；剪映音频统一执行“人声分离 → 仅保留人声 → 人声音量 +10.0dB”。
9. 以最终剪辑音频生成逐字字幕；只允许纠正经音频、词库或人工核实的专业词。
10. 使用 `subtitle.yaml` 的真实字体度量逐行测宽；长句优先拆成连续字幕，必要时允许单个字幕事件最多两行。
11. `bgm.yaml` 支持 `default`、`off`、`custom`；当前 `default` 固定为剪映曲目 `科技主题  Global Technology Background`（素材 ID `7377866594003568681`），音量固定为 -8.0dB，只能在剪映内由有权益的账号使用。
12. 执行 `quality_rules.yaml`；任一硬性检查失败即停止交付。

## 锁定边界

- 画幅选择固定：默认继承源素材实际显示方向；横屏固定使用 16:9 模板，竖屏固定使用 9:16 模板，不允许无授权转换。
- 模板内固定：所选画幅对应的画布、字体、字号、颜色、坐标、间距、比例、动画、字幕安全区、封面恰好两帧和字幕逐字原则。
- 可变：右侧日期、`Day` 序号和依据视频内容确定的封面标题。
- 每条必填：删除区间及理由、速度判断、画面处理判断、音频 A/B/C/D 分类、BGM 模式。
- 剪映音频固定：人声分离启用、模式“仅保留人声”、人声音量 +10.0dB；默认 BGM 音量 -8.0dB。
- 禁止：同步字幕总结、润色、同义替换、增词、漏词、自动缩小、越界，以及未经明确问题授权重新剪辑气口。
- 禁止：因为历史素材多为竖屏而把新横屏素材自动裁成 9:16，或反向把竖屏素材自动改成 16:9。
- 禁止：把剪映音乐缓存复制进代码仓库、迁移包或 FFmpeg 自动混音链路。

## 标题模板 V2

- 开头封面：大号 `MES / 日记` 在黄色四角框内水平及垂直居中，右侧显示日期和大号 `Day`，中下部显示最多两行、逐行居中的内容标题；标题固定采用用户确认的 B 版宋体、82px，仅占第 1、2 帧。
- 正文常驻标题严格参照 `codex-clipboard-997f97ca-ec3a-47a1-8fde-c61387f3aca1.jpg`：大尺寸顶部双区布局、白字黑描边、黄色四角框。
- 正文标题不得再缩为左上角小角标。
